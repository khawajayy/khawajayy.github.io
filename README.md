# Hamza Sadiq — Portfolio

Static portfolio site: plain HTML, CSS and JavaScript, no build step.

- `index.html` — page content and sections
- `style.css` — styling
- `script.js` — project cards (edit the `PROJECTS` list at the top) and animations

Pushing to `main` deploys to https://khawajayy.github.io/ via GitHub Actions.

The previous Next.js site (HAMZA://OS) is preserved on the `old-site` branch.
